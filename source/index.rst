Club Overview
-------------

This short section provides a general overview of what you should do, but its reccommended that you read the exact pages like GitHub Workflow, Installing Unity, etc.

First Time Setup
~~~~~~~~~~~~~~~~

Download each of the following:

* Unity 6.3 LTS
* Git (also create an account on GitHub, make sure you have your username as your full name)
* An IDE of your choice (if you don't know one, just download Visual Studio Code)

* Clone the GitHub Repository (see GitHub Workflow)
* Start working!

GitHub Workflow
~~~~~~~~~~~~~~~

* Commit small changes, not just one big commit
* Push the branch to GitHub
* Open a Pull Request
* A lead will accept it or deny it and provide insight into changes that need to be made
